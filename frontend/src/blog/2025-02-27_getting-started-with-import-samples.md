# Getting started with importing apps and workflows

The fastest way to see WorkflowUI in action is to **import an app and its workflow** instead of building one from scratch. You get a ready-made form and a runnable graph in one go.

---

## Where to Find Sample Files

We provide sample files so you can try this flow with zero setup. Use the **FilesWithWorkflowSamples** folder at the project path:

```
/FilesWithWorkflowSamples
```

Grab an app and workflow from there, then use *Import* in WorkflowUI to load them.

⚠️ You still need the required models on comfyUI in order to run them successfully

---

In a few clicks you’ll have a working app you can run and tweak. It’s a great way to learn the UI and see how workflows and forms fit together. Give it a try when you have a minute—it’s the best way to get a feel for how apps and workflows connect.
